# Vulcanite 0.3 Provider API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `0.3.0-alpha.1` as a neutral prerequisite mod with stable pure-Java Upscaler, Frame Generation, and PresentHook provider APIs, a Minecraft 26.2 Vulkan adapter, Maven/Javadoc publications, compatibility checks, and tracked developer documentation.

**Architecture:** `mgf-api` defines immutable contracts and no loader, Minecraft, or LWJGL dependencies. `mgf-impl-26.2` discovers Fabric entrypoints, deterministically selects one provider per role, owns lifecycle/synchronization/output resources, and hooks the verified final `Minecraft.runTick` blit/present path. Without an active provider, the bridge returns immediately and leaves vanilla's GPU and presentation flow unchanged.

**Tech Stack:** Java 25, Gradle 9, Fabric Loom 1.17.12, Fabric Loader 0.19.3, Minecraft 26.2 unobfuscated sources, Mixin/MixinExtras, LWJGL Vulkan/VMA, JUnit 5.13.4, Maven Publish, Javadoc/doclint.

- [ ] **Step 4: Implement verified mixin hooks**

Target `Minecraft.runTick(Z)V`:

```java
@ModifyArg(
        method = "runTick(Z)V",
        at = @At(value = "INVOKE",
                target = "Lcom/mojang/blaze3d/systems/GpuSurface;blitFromTexture(Lcom/mojang/blaze3d/systems/CommandEncoder;Lcom/mojang/blaze3d/textures/GpuTextureView;)V"),
        index = 1,
        require = 0)
private GpuTextureView mgf$preparePresentSource(GpuTextureView original) {
    return ProviderFrameBridge.beforeBlit(original);
}

@Redirect(
        method = "runTick(Z)V",
        at = @At(value = "INVOKE",
                target = "Lcom/mojang/blaze3d/systems/GpuSurface;present()V"),
        require = 0)
private void mgf$presentFrames(GpuSurface surface) {
    ProviderFrameBridge.present(surface);
}
```

The bridge calls `surface.present()` directly for the fast path. For a generated
batch it presents the already-blitted generated frame, acquires a new texture,
restores real snapshot into main, calls PresentHook, blits/submits/presents real,
and records receipts. Catch provider errors; do not swallow vanilla
`SurfaceException` outside the generated extra-present path.
